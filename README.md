# Jackett Docs

Personal documentation for installing and managing [Jackett](https://github.com/Jackett/Jackett) on macOS.

## Quick Install

```bash
cd ~/Downloads
curl -L -o Jackett.Binaries.macOS.tar.gz https://github.com/Jackett/Jackett/releases/latest/download/Jackett.Binaries.macOS.tar.gz
tar -xzf Jackett.Binaries.macOS.tar.gz
cd Jackett
sudo ./install_service_macos
```

Access the web UI at http://localhost:9117
